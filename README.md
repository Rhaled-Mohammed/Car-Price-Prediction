# Car Price Prediction

A machine learning project for predicting car prices.

## Project Overview

This project explores a car dataset and builds regression models
to predict vehicle prices.

## Project Steps

1. Exploratory Data Analysis
2. Data Preprocessing
3. Linear Regression
4. Gradient Descent
5. Polynomial Regression
6. Model Evaluation

## Models

- Linear Regression
- Polynomial Regression

## Current Results

The initial models achieved relatively low predictive performance.
This version does not yet include categorical encoding or feature
engineering.

These techniques will be added in future iterations.

## Future Improvements

- Encoding categorical features
- Feature engineering
